**📊 Sales & Revenue Analysis Dashboard (Power BI)**

📌 Project Overview
This project presents an interactive **Sales & Revenue Analysis Dashboard** built using Power BI. It helps analyze business performance by visualizing key metrics like sales, profit, product performance, and geographical trends.

🎯 Objectives
- Track overall sales and profit performance
- Identify top-performing products and categories
- Analyze the impact of discounts on profit
- Understand regional and state-wise sales distribution

🛠️ Tools & Technologies
- Power BI
- Excel / CSV Dataset
- DAX (Data Analysis Expressions)

📂 Dataset
- Superstore Sales Dataset
- Includes: Orders, Sales, Profit, Discount, Region, State, Product details

📊 Dashboard Pages
1. Overview Dashboard
- KPI Cards (Total Sales, Profit, Orders, Avg Discount)
- Sales Trend Over Time

- Interactive filters (Region, Category, Date)
- Drill-down capabilities
- Conditional formatting for better insights
- Clean and user-friendly layout

🚀 Key Insights
- High discounts negatively impact profit
- Some sub-categories consistently generate losses
- Certain regions contribute more to overall revenue
- Sales trends show seasonal patterns

⭐ Conclusion
This dashboard provides meaningful business insights through data visualization, helping in better decision-making and performance tracking.
